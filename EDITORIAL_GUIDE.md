# Editorial Guide
**Essay structure:** concrete puzzle → why it matters → relevant evidence and assumptions → what the method does or does not answer → practical decision question.

- Typical length: 800–2,500 words.
- Write for clinicians, statisticians, students, regulators, and thoughtful general scientific readers.
- Separate fact, interpretation, and hypothetical illustration.
- Cite primary literature when claims rely on it. Use mathematical notation only when it clarifies reasoning.
- Use descriptive slugs; avoid renaming public URLs casually.
- Every published essay requires an exact `pubDate: YYYY-MM-DD`; set `updatedDate` for material changes. The published post layout always shows the full date and the byline **Haitao Pan, PhD**.
- All published essays carry an attribution notice: quote, share, or republish with credit to Haitao Pan, PhD, the publication name *Evidence to Decision*, and a link to the canonical original article.
- Mark drafts `draft: true`; set `draft: false` only after explicit publication approval and confidentiality review.
- Each publication requires explicit owner approval and a confidentiality check.
